## 一、项目架构概览

### 1.1 技术栈
- **后端**: Python Flask
- **前端PC端**: Layui + jQuery
- **前端移动端**: 原生HTML/CSS/JavaScript
- **数据库**: SQLite (pear01.db)
- **缓存**: 内存缓存

### 1.2 主要模块
```
applications/
├── view/system/          # 系统管理模块
│   ├── ticket.py         # 工单管理
```

## 七、开发注意事项

### 7.1 移动端开发规范
1. **URL格式**: 所有移动端页面都需要添加 `?mobile=1` 参数
2. **模板继承**: 移动端页面继承 `mobile/base.html`
3. **文件分离**: HTML/CSS/JS分离，不要写内联样式和脚本
4. **响应式**: 使用固定定位的头部和底部导航

### 7.2 常用调试方法
```bash
# 启动开发服务器
python app.py

# 访问移动端页面
http://localhost:5000/m
http://localhost:5000/m/tickets
http://localhost:5000/m/suggestions
```

每次修改后必须更新 `修改记录.md` 文件，格式如下：
