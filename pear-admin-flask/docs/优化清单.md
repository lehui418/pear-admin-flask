## 🔴 待优化问题

### 高优先级（安全问题）

#### 1. 敏感信息硬编码

**位置**: `applications/config.py`

**问题描述**:
- 第 84-85 行：邮箱密码硬编码
- 第 98 行：SECRET_KEY 硬编码且过于简单

**风险**: 🔴 高 - 密钥和密码容易被泄露

**修复方案**:
```python
# 修改前
MAIL_USERNAME = '123@qq.com'
MAIL_PASSWORD = 'XXXXX'
SECRET_KEY = 'pear-system-flask'

# 修改后
import os
MAIL_USERNAME = os.environ.get('MAIL_USERNAME')
MAIL_PASSWORD = os.environ.get('MAIL_PASSWORD')
SECRET_KEY = os.environ.get('SECRET_KEY', 'default-secret-key')
```

**难度**: ⭐ 简单  
**预计时间**: 30分钟

#### 3. CSRF 防护缺失

**位置**: 全系统

**问题描述**:
- 整个系统未配置 CSRF 保护
- 没有设置 `WTF_CSRF_ENABLED`

**风险**: 🔴 高 - 攻击者可构造恶意网站诱导操作

**修复方案**:
```python
# config.py 添加
WTF_CSRF_ENABLED = True
WTF_CSRF_TIME_LIMIT = None

# 前端表单添加 CSRF token
<input type="hidden" name="csrf_token" value="{{ csrf_token() }}">
```

**难度**: ⭐⭐ 中等  
**预计时间**: 1小时

#### 4. 文件上传安全问题

**位置**: 
- `applications/view/system/upload.py` (第 12-50 行)
- `applications/common/utils/upload.py` (第 23 行)

**问题描述**:
- 仅检查 MIME 类型，可被伪造
- 未验证文件扩展名
- 未检查文件内容

**风险**: 🔴 高 - 可能上传恶意文件执行代码

**修复方案**:
```python
ALLOWED_EXTENSIONS = {'.jpg', '.jpeg', '.png', '.gif', '.pdf'}

def allowed_file(filename):
    return '.' in filename and \
           filename.rsplit('.', 1)[1].lower() in ALLOWED_EXTENSIONS

# 修改前
if not mime.startswith('image/'):

# 修改后
if not allowed_file(photo.filename):
    return fail_api(msg="不支持的文件类型")
```

**难度**: ⭐⭐ 中等  
**预计时间**: 1小时

### 低优先级（性能问题）

#### 9. N+1 查询问题

**位置**: `applications/view/system/ticket.py` (第 298-342 行)

**问题描述**:
- 查询工单列表时可能产生 N+1 查询
- 每次查询工单后，再查询关联的用户、部门等信息

**风险**: 🟢 低 - 数据量大时性能下降

**修复方案**:
```python
# 使用 joinedload 预加载
from sqlalchemy.orm import joinedload

# 修改前
tickets = Ticket.query.all()
for ticket in tickets:
    user = ticket.user  # 触发额外查询

# 修改后
tickets = Ticket.query.options(
    joinedload(Ticket.user),
    joinedload(Ticket.assignee)
).all()
```

**难度**: ⭐⭐ 中等  
**预计时间**: 1-2小时
